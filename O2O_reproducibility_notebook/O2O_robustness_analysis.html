# Supplementary exact TreeSHAP

Exact native XGBoost TreeSHAP is used without an interventional background dataset. It exports 714 rows per category, base values, predictions, mean absolute values, LOWESS curves and figures. Additivity is checked. These exports do not overwrite or establish pixelwise identity with the original manuscript figures.

Old statsmodels robust LOWESS can produce nonfinite curves on repeated zero values. A disclosed zero-iteration smoothing fallback is used when fewer than 80% of points are finite; the iteration count is exported. Raw TreeSHAP values are unchanged. The original images are preserved separately.
